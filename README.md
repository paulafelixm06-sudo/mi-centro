# Centro de Paula · app para iPhone

App y widget con casillas para tachar las tareas del Centro de Paula.

- La app lee la copia que deja el Centro en el calendario (evento escondido «datos del widget», 1 ene 2030).
- Lo que se tacha aquí se apunta en otro evento escondido («tachados desde el iPhone», 2 ene 2030) y el Centro lo marca al abrirse.
- GitHub la fabrica sola en cada cambio: la última versión está en *Releases → ultima → CentroDePaula.ipa*.
- Se instala con AltStore (cuenta de Apple gratuita).
